# fpga-music
本项目基于FPGA，实现纯硬件并行的实时电子乐器引擎。依托 FPGA 并行架构搭建音频合成通路，通过矩阵键盘与压感模块完成演奏输入，支持多音色切换，具备 ADSR 包络、颤音、滑音、弯音及合唱、延迟音效。 采用分时复用架构优化存储开销，实现多声部并发合成，混音后经音频编解码器输出立体声。系统支持演奏事件录制，借助 Flash 完成曲谱持久化与脱机播放，通过蓝牙、串口对接上位机与微信小程序，实现参数配置与曲谱下发。 驱动 LCD、灯带及数码管，实现声部状态、包络与键位灯光联动反馈。音频通路全部由 Verilog 硬件逻辑实现，无需软核参与。软硬件协同实现演奏、合成、存储与交互。
