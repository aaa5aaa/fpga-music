# EC11 音量旋钮（已合并进蓝牙+音色工程）

本版在原来的“蓝牙曲库 + 修正音色”工程上加入了 **EC11 旋转编码器总音量**。

## 1. 改了哪些文件

| 文件 | 改动 |
|---|---|
| `src/rotary_vol.v` | **新增**：EC11 正交解码 + 64 档对数音量表 + 转动加速 |
| `src/acg720_instrument.v` | 新增 `rot_a/rot_b/rot_sw` 端口、`u_vol` 例化、混音后的 Q8 音量乘法与限幅 |
| `src/fpga_project.cst` | 新增 3 个旋钮引脚 |
| `fpga_project.gprj` / `build.tcl` | 加入 `src/rotary_vol.v` |

## 2. 引脚

| 信号 | 引脚 | 说明 |
|---|---|---|
| `rot_a` | **B16**（GPIO0_17） | EC11 A 相，内部上拉 |
| `rot_b` | **E16**（GPIO0_20） | EC11 B 相，内部上拉 |
| `rot_sw` | **E17**（GPIO0_27） | 旋钮按下，本版**未使用**，可悬空 |

> D14/D15 仍然留给蓝牙 UART（`bt_rx/bt_tx`），旋钮没有占用它们。

## 3. 接线

EC11 一般 5 个脚：A、B、C（公共端）、两个按键脚。

```
EC11 A  ── B16
EC11 B  ── E16
EC11 C  ── GND（公共端）
按键    ── E17 + GND（可选，本版不用）
```

- 编码器是纯机械开关，不需要供电；如果买的是带板子的模块，VCC 接 3.3V 即可；
- A/B 内部上拉，公共端接 GND，转动时 A/B 依次拉低。

## 4. 行为

| 项目 | 说明 |
|---|---|
| 档位 | 0–63，共 64 档 |
| 上电默认 | **42 档 = 1.00x** |
| 0 档 | 静音 |
| 63 档 | 1.50x（比基础音量大约 +3.5dB） |
| 转动加速 | 间隔 <10ms 每格走 3 档，<30ms 走 2 档，否则 1 档 |
| 作用位置 | **混音之后**，对 32 声部、蓝牙曲谱、上电自检音都生效 |
| 与力度关系 | 逐声部力度 × 总音量，两者相乘，互不覆盖 |

> 本版**没有**给旋钮加 LED 指示；D7 仍然是“蓝牙连接常亮 / 否则心跳”。如果想看旋钮动作，可以再加一个“转动时 D6 闪 50ms”的调试逻辑（v15 原版有）。

## 5. 编译方法

工程没有附带比特流，需要你自己综合：

1. Gowin IDE 打开 `fpga_project.gprj`；
2. 确认文件列表里有 `src/rotary_vol.v`（`.gprj` 已加）；
3. **Synthesize → Place & Route**；
4. Program Device 下载新生成的 `impl/pnr/project.fs`。

预计资源和时序变化很小：只多一个 6 位音量寄存器、一个 10 位增益表和一个 16×10 乘法（约 1 个 DSP 或少量 LUT）。

## 6. 注意

- 本工程是**源码包**，不包含 `impl/` 里的旧比特流；不要拿旧 `project.fs` 下载，否则没有旋钮功能；
- `variant_led01/` 是“恢复 LED0/LED1”的变体，里面**没有**旋钮逻辑，两者要同时用需要再合并；
- 之前计划的 8 路红外原本想用 B16/E16/E17，现在被旋钮占用；如果以后加红外，改用
  `B17、B18、C18、C19、D20、D17、E18、E19` 这 8 个脚即可。
