# 音色升级说明（v11：单 ROM 分时读 + 修正版）

本版在 `src/synth_voice.v` 中加入 1024 点、12 位正弦波表，并把四种音色改为波表驱动：

- `timbre=0`：钢琴风格，基频 + 2/3/4 次谐波 + Attack 起音噪声。
- `timbre=1`：弦乐风格，基频 + 中高次谐波，适合颤音。
- `timbre=2`：二算子 FM 风格，调制器改变载波相位。
- `timbre=3`：管风琴风格，基频 + 2/4 倍频和声。

## 本版关键改动

### 1. 每声部只放 1 个同步 ROM

上一版每个声部并行实例化 5 个 `sine_lut`，32 声部就是 160 个 1024×12 ROM，需要 160 块 BSRAM（器件只有 118 块），或者约 12 万 LUT4，装不下。

本版改成：

- 每声部 **1 个** `sine_lut`（1024×12，同步读，1 拍延迟）；
- 每采样周期用 **7 拍** 依次读：基频、2 次、3 次、4 次、FM 相位；
- 32 声部 = **32 块 BSRAM**，加原有 3 块、蓝牙曲库 8 块，共 43 块，余量充足；
- 7 拍 @50MHz = 140ns，远小于 20.5µs 采样周期，时序很稳。

### 2. 修正输出缩放

上一版 `oscillator = osc_mix >>> 2`，`osc_mix` 最大约 3867，缩放后 966；再乘 `gain12` 再 `>>>5`，最大约 123,134，远超 16 位有符号的 32,767，按住键约 20ms 后就会溢出失真。

本版改成：

```verilog
oscillator = (osc_mix >>> 5) + noise_term;   // 3867 -> 120
```

单声部最大约 `120 × 4079 ÷ 32 = 15,296`，和旧版 ±128 的 16,316 接近，32 声部混音也不会明显削顶。

### 3. 修正 FM 相位偏移位宽

上一版：

```verilog
wire signed [23:0] fm_offset = $signed(sine2) <<< 5;
```

Verilog 移位结果宽度等于左操作数（12 位），高位被截断后再符号扩展，实际偏移是错的。本版：

```verilog
wire signed [23:0] fm_offset = {{12{s2[11]}}, s2} <<< 10;
```

先符号扩展到 24 位，再左移 10 位（约 ±12.5% 周期），FM 才有可听的调制。

### 4. 起音噪声不再被吃掉

噪声改到缩放之后：

```verilog
noise_term = (st == S_ATT) ? (attack_noise_12 >>> 4) : 0;  // ±8
```

不会被 `>>>5` 移成 0。

## 资源

| 项目 | 数量 |
|---|---|
| BSRAM（正弦 ROM） | 32 块（1024×12） |
| BSRAM（原有 + 蓝牙曲库） | 3 + 8 块 |
| DSP | 不变（每声部 2 个乘法） |
| LUT | 比上一版 160 个并行 ROM 少一个数量级 |

## 验证

1. `.gprj` 和 `build.tcl` 已经加入 `src/sine_lut.v`；在 Gowin IDE 里确认文件列表里有它。
2. 重新综合，检查报告：
   - `sine_lut` 是否推断成 BSRAM（32 块，而不是分布式 LUT）；
   - 有没有 “initial value ignored” 警告（有的话 ROM 上电可能是全 0，需要改 `.mi` 初始化）；
   - 时序是否满足 50MHz。
3. 分别切换四种 `timbre`，用示波器/频谱仪看波形和谱峰。
4. 重点听：
   - 按住一个键 1 秒，音量爬升过程中是否还有“破音/反相”；
   - timbre=2 是否有明显 FM 边带；
   - timbre=0 的起音是否有轻微噪声。

## 和蓝牙工程合并

本目录是“无蓝牙”的 v12 版本。如果要把音色升级合并到蓝牙工程：

1. 只复制 `src/synth_voice.v` 和 `src/sine_lut.v`；
2. 在蓝牙工程的 `fpga_project.gprj` / `build.tcl` 里加 `sine_lut.v`；
3. **不要**覆盖蓝牙工程的 `acg720_instrument.v` 和 `fpga_project.cst`，否则蓝牙的 UART/曲库会被冲掉；
4. `synth_voice` 的端口没有变化，蓝牙顶层可以直接例化。

## 已知取舍

- 每声部一个 ROM 是 32 份相同内容；资源够用，逻辑最简单。若以后要更省 BSRAM，可以改成“全局 1 份波表 + 32 路时分复用”，但顶层要加调度器。
- `sine_lut` 的 `initial` 初始化依赖 Gowin 对 BSRAM 初值的支持；综合报告里要确认。
- 四种音色仍是“正弦 + 谐波”的简化模型，不是真实乐器采样；钢琴的谐波衰减、弦乐的弓噪等没有建模。
