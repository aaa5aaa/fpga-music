# 曲谱 JSON 格式

这些 JSON 文件可以同时导入 PC 上位机和微信小程序。建议使用 `欢乐颂.json` 或 `铃儿响叮当.json` 进行完整演示。

## 曲目

| 文件 | 说明 |
|---|---|
| `小星星.json` | 完整版小星星，含低音伴奏和结尾 |
| `小星星简版.json` | 较短的快速导入测试曲 |
| `铃儿响叮当.json` | 完整段落，含主旋律、伴奏和结尾 |
| `欢乐颂.json` | 完整段落，含变化段和伴奏 |
| `两只老虎.json` | 完整段落，含重复主题、尾段和伴奏 |

示例统一采用“高音区主旋律 + 低音区伴奏”的编排。主旋律力度约为 190，伴奏力度约为 38；同一音高不会重叠 note-on，所有音符都有对应的 note-off，停顿通过 delta_ms 表示。

## 格式

```json
{
  "name": "曲名",
  "events": [
    [120, 12, 190],
    [336, 12, 0],
    [24, 0, 44]
  ]
}
```

每个事件 3 个数：

| 字段 | 范围 | 含义 |
|---|---|---|
| delta_ms | 0..65535 | 距离上一个事件的毫秒数 |
| note | 0..31 | 音高，0=C4，2=D4，4=E4，5=F4，7=G4，9=A4 |
| velocity | 0..255 | 0=note off，1..255=note on 力度 |

限制：

- 最多 4095 个事件；
- note 只能使用 0..31；
- 第一个事件建议预留约 100ms；
- 最后一个音符必须发送 velocity=0 的 note-off。

## 导入方式

PC 端选择“曲库 → 导入曲谱”，选择 JSON 文件即可。

微信小程序中点击“选择 JSON 曲谱”，从微信聊天文件中选择本目录的曲谱文件即可。
